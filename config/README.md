# 電子婚紗 · 使用與編輯說明

## 一、資料夾在做什麼

```
電子婚紗/
├── index.html         ← 【雙擊這個打開】用瀏覽器看相簿
├── photos/            ← 壓縮過的網頁用圖（網頁實際讀這裡）★上傳
├── music/             ← 背景音樂 bgm.mp3 放這裡        ★上傳
├── config/
│   ├── album.js       ← ★ 你要改內容，只要改這一個檔 ★  ★上傳
│   └── README.md      ← 就是本檔
├── assets/
│   ├── style.css      ← 配色與版面（進階微調用）        ★上傳
│   └── book.js        ← 翻頁程式（不用動）              ★上傳
├── 照片/              ← 原始大圖（母帶，不要動，也不要上傳）
└── 工具/
    ├── 重新產生相片.py ← 加了新照片時用來壓縮（不用上傳）
    └── 挑片預覽/       ← 全部照片的縮圖總覽，挑片用（不用上傳）
```

資料夾名稱都是英文，是為了放上網後網址乾淨、不會出現一長串編碼。

原則只有一句：**大圖放「照片」，網頁用圖在 `photos`，文字都在 `album.js`。**

---

## 二、最常做的三件事

### 1. 改文字（標題、章節名、照片旁的小字）

用記事本或 VS Code 打開 `config/album.js`，改引號 `" "` 中間的字，存檔，
回瀏覽器按 **F5**（重新整理）就看得到。

> 注意：不要刪掉引號、逗號、大括號。中文標點沒關係，寫在引號裡就好。

### 2. 換照片 / 調順序

在 `album.js` 裡面，每一頁長這樣：

```js
{ 型: "滿版", 圖: "DSC00560.jpg", 說明: "早晨八點，還沒有人來" },
```

- 想換照片 → 把 `圖:` 後面的檔名換掉
- 想調順序 → 把整行剪下、貼到別的位置
- 想刪掉這頁 → 把整行刪掉
- 想新增一頁 → 複製一整行，貼在下面，改檔名

**五種版型可以用：**

| 型 | 效果 | 寫法 |
|---|---|---|
| `滿版` | 一張照片一整頁 | `{ 型:"滿版", 圖:"A.jpg", 說明:"" }` |
| `雙直` | 兩張直式並排 | `{ 型:"雙直", 圖:["A.jpg","B.jpg"], 說明:"" }` |
| `雙橫` | 兩張橫式上下疊 | `{ 型:"雙橫", 圖:["A.jpg","B.jpg"], 說明:"" }` |
| `連拍` | 三張橫式錯開排成一條底片 | `{ 型:"連拍", 圖:["A.jpg","B.jpg","C.jpg"], 說明:"" }` |
| `文字` | 整頁只有一段話 | `{ 型:"文字", 主文:"第一行\n第二行", 署名:"" }` |
| `空白` | 留白，調節奏用 | `{ 型:"空白" }` |

`說明` 留空 `""` 就不會出現小字。文字裡的 `\n` 代表換行。

### 3. 放背景音樂

把 mp3 檔案丟進 **`music/`** 資料夾，檔名改成 **`bgm.mp3`** 就好。

如果不想改檔名，就到 `album.js` 最上面把 `檔名:` 改成你的檔名。
音量在同一段的 `音量:`，`0.35` 大概是三成，可以改 `0` ~ `1`。

> 檔案盡量壓在 5MB 以內，賓客用手機 4G 開才不會卡。

**自動播放的設計：** 一打開網頁會先出現封面問候畫面，上面兩顆按鈕
「♪ 開啟音樂並開始」和「靜音瀏覽」，由看的人自己決定。
進去之後右上角隨時可以開關。（瀏覽器本來就禁止未經點擊的自動播放，
這個做法是唯一能穩定播放又不惹人厭的方式。）

## 三、加了新照片怎麼辦

1. 把新照片放進 `照片/`
2. 執行 `工具/重新產生相片.py`（需要電腦有 Python + Pillow）
   - 命令列：`python 工具/重新產生相片.py`
   - 它只會處理還沒壓縮過的新檔案，不會重跑舊的
3. 到 `config/album.js` 把新檔名安排進想要的章節

> 沒裝 Python 也沒關係 —— 直接在 Claude 這裡說「我加了新照片，幫我重新產生」，
> 我會直接幫你跑完並更新設定檔。

**檔名一律用小寫 `.jpg`。** 本機 Windows 不分大小寫，但放到網路上會分，
`.JPG` 和 `.jpg` 混用會變成破圖。

---

## 四、想改顏色或字體

打開 `assets/style.css`，最上面那一段 `:root{ ... }` 就是全部的顏色與字體，
改那幾個色碼就會整本一起變。

```css
--紙:   #F6F1E9;   /* 頁面米白 */
--墨:   #3B352E;   /* 主要文字 */
--金:   #B08D57;   /* 點綴線條 */
```

## 五、怎麼傳給別人看

- **最簡單**：把整個資料夾壓縮成 zip 傳給對方，對方解壓後雙擊 `index.html`。
- **一條網址給賓客掃 QR code**：上 GitHub（repo 設 Private）再接 Cloudflare Pages。

  只上傳這五樣，其他都不要傳：

  ```
  index.html
  photos/
  music/
  config/
  assets/
  ```

  Cloudflare Pages 設定頁三個欄位：
  Framework preset = **None**、Build command = **留空**、Build output directory = **`/`**

## 六、操作方式（給看的人）

| 裝置 | 翻頁 |
|---|---|
| 電腦 | 點左半邊 / 右半邊、← → 方向鍵、空白鍵、滑鼠滾輪 |
| 手機 | 左右滑動，或點下方 ‹ › |

右上角有「目錄」可以直接跳章節。

## 兩個排版上的注意事項（2026-09-06 新增）

**「連拍」只放同一組動作的連續瞬間。**
三張要是**同一個場景、同一套衣服**的前後三格（例如：拋球 → 接球 → 偷親）。
拿不同風格的照片來湊，翻起來會很怪 —— 它的重點是「看得懂順序」。
三張都要是**橫式**照片，直式排進去會嚴重縮小。

**「雙直」的說明請控制在 11 個字以內。**
手機直式時雙直頁會變成錯位疊圖，說明排在左下角的空隙，
實測 11 字以內排得成一行，12 字就會折行還可能掉一個孤字。
其他版型（滿版、雙橫、連拍）沒有這個限制。

**「雙直」挑照片時注意主圖的右下角。**
手機直式的錯位疊圖，副圖會壓住主圖的**右下角**。
所以第一張（主圖）盡量挑「人物在上半部或偏左」的照片，
主體站在右下角的照片放主圖會被蓋到臉。
