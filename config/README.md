# 編輯說明 — Our Story（美式編輯版）

你只需要動 **`config/album.js`** 這一個檔案。改完存檔，回瀏覽器按 **F5** 就生效。

---

## 一、放照片

照片放在 **`photos/`** 資料夾，檔名要跟 `album.js` 裡寫的一模一樣（含大小寫、`.jpg`）。

## 二、放音樂

mp3 放進 **`music/`**，預設檔名 `bgm.mp3`。要換檔名的話，改 `album.js` 最上面的：

```js
音樂: { 檔名: "bgm.mp3", 音量: 0.32 }
```

音量 0～1。賓客一進來會看到「開啟音樂並開始 / 靜音瀏覽」兩顆按鈕自己選，
右上角也隨時可以切換。

## 三、版型（`型`）

| 型 | 效果 | 適合的照片 | 佔幾頁 |
|---|---|---|---|
| `滿版` | 一張照片出血到頁緣 | **直式**（橫式會被裁掉兩邊） | 1 |
| `跨頁` | 一張照片橫跨左右兩頁 | **橫式**，比例接近 3:2 最漂亮 | 2 |
| `留白` | 照片縮小、四周大留白 | 直式橫式都可以（**框會照圖片實際長寬開，不會裁到照片**） | 1 |
| `雙直` | 兩張直式照片 | 直式 ×2 | 1 |
| `雙橫` | 兩張橫式上下疊 | 橫式 ×2 | 1 |
| `文字` | 一整頁的文字 | — | 1 |
| `空白` | 留白頁 | — | 1 |

**`跨頁` 有一個規則**：它必須落在「左頁＋右頁」上，所以程式會在需要的時候
自動插一張空白頁去對齊。你不用管，但頁數會因此多一頁。

`留白` 的橫式／直式是程式讀圖片實際長寬**自動判斷**的，你不用標：
- **直式照片** → 照片偏一邊、說明**直排**在外側
- **橫式照片** → 照片整張置中、說明**橫排在照片下方**（橫圖旁邊塞不下直排字）

**`跨頁` 要先確認書縫落在哪。** 書縫會落在照片的正中央，
所以主角站在正中間的照片**不要用跨頁**（會被切成兩半）。
判斷方法：把照片裁成 1.56:1 再在正中央畫一條線，壓到人就改用 `留白`。
已經檢查過的：00556 / 00619 / 00631 / 00676 / 07132 可以跨頁；
07072B（牽手在正中央）和 07123（LOVE 會被切斷）已改成 `留白`。

## 四、說明文字的長度

| 位置 | 建議長度 | 超過會怎樣 |
|---|---|---|
| `留白`（直式）的直排說明 | **19 字以內** | 會折成第二欄 |
| `留白`（橫式）照片下方的說明 | 22 字以內 | 會折行 |
| `雙直` 在手機直式 | **13 字以內** | 會折成兩行（還是好看，只是版面比較滿） |
| `滿版`／`跨頁` 壓在照片上 | 20 字以內 | 會折行 |
| 章名（`標題`） | **5 個字以內** | 手機直式會折成平均兩行 |

## 五、每章的顏色

每一章的 `色:` 會決定那一章的細線、章號、說明前的小短線的顏色。
填一般的色碼就好，例如 `"#9E4038"`。

## 六、想調翻頁的快慢

改 **`assets/style.css`** 最上面的：

```css
:root      { --flip: 1.05s; }   /* 電腦、平板 */
body.thin  { --flip: .62s;  }   /* 手機（直式橫式都算） */
```

**只要改這兩個數字就好**，JS 會自己讀，陰影也會自己跟著走。

⚠️ 如果連 `--flip-ease`（加速曲線）也要換，那 `style.css` 檔尾的
`@keyframes pageShadePC / pageShadeM` 必須用同一條貝茲曲線重新推算
（那組數字是 `opacity = |sin(180° × ease(p))|` 算出來的，不能用手調）。

## 七、上線

跟舊版一樣：GitHub（Private）→ Cloudflare Pages。
要上傳的是 `index.html` + `photos/` + `music/` + `config/` + `assets/`。
